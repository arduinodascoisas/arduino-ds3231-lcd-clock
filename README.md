# Relogio_LCD
Relógio Arduino: conecte LCD Keypad Shield e RTC DS3231 (I2C: VCC-5V, GND-GND, SDA-A4, SCL-A5). Instale RTClib, crie a pasta 'Relogio_LCD_advanced' com arquivos Relogio_LCD_advanced.ino, Alarme.ino e Menu_Alarme.ino. Recursos: menu com modo turbo (botões UP/DOWN), filtro digital em A0 e alarme estroboscópico desligável por qualquer botão.
